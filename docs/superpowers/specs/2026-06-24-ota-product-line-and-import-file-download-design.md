# OTA 任务产线归属与文件导入原文件下载设计

## 1. 背景

新增 OTA 任务时，目标固件版本已经是任务审批归属的重要判断依据。为了让创建人确认目标版本归属，同时避免暴露审批负责人和审批规则，页面需要在选择目标固件版本后自动展示该版本的所属产线。

另外，文件导入任务在任务详情中只能查看执行结果和异常明细，缺少对创建任务时上传设备列表原文件的追溯入口。用户需要在任务复盘、审批核对或问题排查时下载原始设备清单。

## 2. 设计目标

- 在新增任务、预览发布、任务详情中展示目标固件版本对应的所属产线。
- 所属产线由目标固件版本自动带出，用户不可修改。
- 前台只展示 `所属产线：IPC`，不展示审批负责人和审批规则。
- 文件导入任务详情支持下载创建任务时上传的设备列表原文件。
- 明确“下载原文件”“导出设备明细”“下载异常明细”的差异，避免入口混淆。

## 3. 非目标

- 不新增产线选择控件。
- 不允许创建人手动修改所属产线。
- 不在前台展示审批负责人。
- 不在前台展示“按目标固件版本所属产线提交审批”等规则说明。
- 不为指定版本或手动导入任务展示“下载原文件”按钮。

## 4. 所属产线设计

### 4.1 数据关系

目标固件版本与所属产线是一对一关系。

示例：

| 目标固件版本 | 所属产线 |
| --- | --- |
| 23.422.209.17 | IPC |

### 4.2 新增任务展示

在新增任务第 1 步“基础信息”中，目标固件版本字段选择后，在目标版本后方展示只读标签：

```text
23.422.209.17（已上架）  所属产线：IPC
```

展示规则：

- 未选择目标固件版本时，不展示所属产线标签，或展示为空态 `所属产线：-`。
- 选择目标固件版本后，系统自动带出所属产线。
- 切换目标固件版本后，所属产线同步刷新。
- 所属产线不可编辑。

### 4.3 预览发布展示

在预览发布的“基本信息”摘要中，所属产线跟随目标固件版本展示，不作为独立字段：

```text
目标固件版本：23.422.209.17  所属产线：IPC
```

该字段用于提交前确认版本归属，不展示审批负责人和审批规则。

### 4.4 任务详情展示

在任务详情的目标版本展示中追加所属产线标签，不作为独立 KPI 或独立字段：

```text
目标版本：23.422.209.17  所属产线：IPC
```

已提交任务展示提交时的所属产线快照。编辑草稿或复制重建时，按当前目标固件版本重新带出所属产线。

### 4.5 校验与异常

进入下一步或提交发布时，如果目标固件版本未配置所属产线，则拦截并提示：

```text
当前目标固件版本未配置所属产线，请先维护版本产线归属。
```

该异常属于基础信息校验，不进入策略配置和预览发布。

## 5. 文件导入原文件下载设计

### 5.1 展示范围

仅当任务升级方式为 `文件导入` 时，在任务详情中展示“下载原文件”按钮。

以下任务不展示该按钮：

- 指定版本
- 手动导入

### 5.2 推荐位置

按钮放在任务详情中“设备来源”信息旁边，贴近上传文件信息。

示例：

```text
设备来源：已导入设备清单：ipc_hangzhou_20260601.xlsx
共 664 台设备，按设备所属大区自动分发。

[下载原文件]
```

该入口不放在设备明细工具栏中，避免与执行结果导出混淆。

### 5.3 状态规则

文件导入任务在以下状态均可展示“下载原文件”：

- 待审批
- 已驳回
- 已失效
- 待执行
- 升级中
- 中止中
- 已完成
- 已结束

按钮状态：

| 状态 | 展示 |
| --- | --- |
| 可下载 | `下载原文件` |
| 下载中 | `下载中...` |
| 不可下载 | 按钮置灰，提示 `原文件暂不可下载` |

不可下载场景包括：

- 历史任务未保存原文件。
- 原文件已过期。
- 当前用户无下载权限。
- 后端文件服务返回不可用。

### 5.4 下载内容

“下载原文件”下载的是创建任务时上传的设备列表原始文件，不是预检结果，也不是执行结果。

建议下载文件名：

```text
OTA202606010001_ipc_hangzhou_20260601.xlsx
```

如果产品希望尽量保留用户上传体验，也可以直接使用原文件名：

```text
ipc_hangzhou_20260601.xlsx
```

### 5.5 与其他下载入口的区别

| 入口 | 含义 | 适用位置 |
| --- | --- | --- |
| 下载原文件 | 创建任务时上传的设备列表原始文件 | 文件导入任务详情的设备来源旁 |
| 导出设备明细 | 任务执行后的设备状态、升级结果、失败原因 | 升级明细设备列表工具栏 |
| 下载异常明细 | 预检或执行过程中产生的异常设备列表 | 预览发布或异常分类区域 |

## 6. 数据字段建议

### 6.1 任务基础字段

| 字段 | 说明 |
| --- | --- |
| targetVersion | 目标固件版本 |
| productLineCode | 所属产线编码 |
| productLineName | 所属产线名称，页面展示为 `IPC` |
| productLineSnapshot | 提交任务时的产线快照 |

### 6.2 文件导入字段

| 字段 | 说明 |
| --- | --- |
| importFileId | 原文件 ID |
| importFileName | 原文件名称 |
| importFileSize | 原文件大小 |
| importFileUploadedAt | 原文件上传时间 |
| importDeviceCount | 原文件识别设备数 |
| importFileAvailable | 原文件是否可下载 |
| importFileDownloadUrl | 原文件下载地址，或由下载接口动态获取 |

### 6.3 下载接口建议

前端可通过任务 ID 下载原文件：

```text
GET /ota/tasks/{taskId}/import-file/download
```

后端根据任务 ID 校验：

- 任务是否为文件导入。
- 用户是否有任务详情或文件下载权限。
- 原文件是否仍可用。
- 返回文件流或临时下载地址。

## 7. 页面验收标准

### 7.1 所属产线

- 选择目标固件版本后，在目标版本后方展示 `所属产线：IPC`。
- 所属产线不可编辑。
- 切换目标固件版本后，所属产线同步刷新。
- 预览发布在目标版本后方展示所属产线。
- 任务详情在目标版本后方展示所属产线。
- 页面不展示审批负责人。
- 页面不展示审批规则说明。
- 目标固件版本未配置所属产线时，无法进入下一步或提交发布。

### 7.2 文件导入原文件下载

- 文件导入任务详情展示“下载原文件”按钮。
- 指定版本任务详情不展示“下载原文件”按钮。
- 手动导入任务详情不展示“下载原文件”按钮。
- 点击“下载原文件”下载创建任务时上传的设备列表原始文件。
- “下载原文件”与“导出设备明细”“下载异常明细”入口和含义清晰区分。
- 原文件不可用时按钮置灰，并提示 `原文件暂不可下载`。

## 8. 开放问题

- 原文件下载名最终采用原文件名，还是 `任务ID_原文件名`。
- 历史文件的保留周期是否有限制。
- 文件导入原文件下载是否需要单独权限，还是复用任务详情查看权限。
